# Contributing

Thank you for considering contributing to the Poly Contracts repository!

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/your-feature`)
3. Commit your changes
4. Ensure all tests pass
5. Open a Pull Request

## Development Workflow

- Run `make generate` to regenerate code
- Run `make lint` to lint protobuf files
- Run `make test` (placeholder) for tests

## Code Style

- Follow the existing code style
- Keep protobuf definitions clean and well-documented
- Add appropriate comments

## Testing

- Write unit tests for any new functionality
- Ensure generated code is not manually modified

## Issue Reporting

- Open an issue if you find a bug or have a feature request
- Provide a clear and concise description
