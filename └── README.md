
## Getting Started

### Prerequisites

- **Buf** – Code generation tool for Protocol Buffers. Install from https://buf.build/docs/installation
- **Go** (≥ 1.20) – For generating Go code.
- **Python** (≥ 3.9) – For generating Python code.
- **Java** (≥ 11) – For generating Java code.
- **PHP** (≥ 8.0) – For generating PHP code.

> **Tip:** The `scripts/generate.sh` script will automatically install missing dependencies if they are not found.
